# Browser Workflow (Claude plugin)

**Tell Claude what you do on a website once. It saves it as a workflow that runs fast in your own Chrome, in the background, while you keep working.**

This is the Claude part of Browser Workflow 2. It works together with the Browser Workflow Chrome extension, which does the work in Chrome.

Status: in development. Install instructions come with the first release.
